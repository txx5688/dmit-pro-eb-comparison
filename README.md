# DMIT Pro 和 EB 区别：回程线路、同价位流量差，以及电信/联通/移动到底该怎么选

会搜这个问题的人，一般已经跳过"DMIT 是干什么的"这一步了——你知道它卖美西、香港、东京的 KVM VPS，也知道它贵、线路好。真正卡住你的是最后一道选择题：同样是洛杉矶机房，同样是 AMD EPYC，同样写着"中国优化"，Pro 和 EB 到底差在哪，多花的钱值不值。

先把结论压缩成三句话：

- CPU、内存、SSD、虚拟化架构，Pro 和 EB 没有区别，区别在网络配置。
- Pro 的回程收在电信 CN2 GIA，EB 的回程收在联通 AS9929 和移动 CMIN2。
- 同一个档位，EB 给的月流量和端口带宽通常比 Pro 多一大截，价格却一样。

下面把这三句话拆开。

## 先分清 Pro、EB、T1：前两个是优化线路，第三个不是

DMIT 按网络质量把产品切成三条线：

- **Premium（简称 Pro）**：官方产品页的描述是"接入包括中国电信 CN2 GIA 在内的高级传输资源"。
- **Eyeball（简称 EB）**：官方描述是"Tier 1 加上面向中国路由的尽力优化"（Reasonable Effort）。注意"尽力"两个字，这不是 SLA 级别的承诺。
- **Tier 1（简称 T1）**：纯国际骨干互联，中国方向不做任何优化。

关键点在 Pro 和 EB 的关系上。很多人以为 EB 是"低配版 Pro"，其实不太准确——两个都是优化线路，都是双向优化，只是把回程交给了不同运营商的精品网。所以 EB 不是 Pro 的阉割版，而是走另一条路的同级产品。

顺带说清 T1 的位置：它便宜得多，年付 $36.9 起，但超量后限速和路由都不面向国内，买它是拿来做落地和国际业务的，不是拿来直连看视频的。

## 回程路由才是分水岭

以洛杉矶机房为例，Pro 和 EB 的路由差异大致是这样的：

| 对比项 | Premium（Pro） | Eyeball（EB） |
| --- | --- | --- |
| IPv4 回程 | 三网 CN2 GIA（AS4809） | 9929 / CMIN2 动态负载 |
| IPv6 回程 | 9929 / CMIN2 | 9929 / CMIN2 |
| 电信方向 | 去程 CN2 GIA | 去程 CN2 GIA |
| 联通方向 | 去程 AS4837 直连，回程 CN2 GIA | 回程 AS9929（联通精品网） |
| 移动方向 | 去程 CMI，回程 CN2 GIA | 全程 CMIN2 |
| 官方定位 | 一等运营商 + CN2 GIA 等高级传输 | Tier 1 + 面向中国尽力优化 |

读这张表有一个容易忽略的细节：**Pro 的 IPv4 走 CN2 GIA，IPv6 反而走 9929/CMIN2；EB 的 IPv4 和 IPv6 统一走 9929/CMIN2。** 也就是说，如果你主要用 IPv6，Pro 在回程上并不比 EB 高级。Pro 的优势集中在 IPv4 的单栈表现上。

CN2 GIA 的价值在晚高峰。它是电信的顶级承载网，拥堵时段优先级最高，抗丢包能力强。9929 和 CMIN2 也是精品网，日常状态下体验和 GIA 很接近，但优先级低一档，遇到国际出口整体拥堵时会先让路。这就是 Pro 溢价的全部理由，也是它唯一不可替代的地方。

## 线路和流量之外，Pro 和 EB 基本是同一套规则

选完之后的使用体验，两系几乎共享同一套政策，这部分值得单独说清楚，因为它是很多人纠结时忽略的：

- **超量降速，不停机。** 月流量跑完不会关机，端口被压到 4Mbps / 8Mbps / 10Mbps 这个量级继续跑（档位越高限速值越高）。做网站的人应该理解这意味着什么：突发流量顶穿了额度，站还在，只是慢。
- **每 15 天可以免费换一次 IP。** 条件大致是：实例已购买满 7 天、距上次换 IP 满 15 天、服务剩余有效期满 7 天，并且 IP 的 ICMP 和全部 TCP 端口都被封。不满足免费条件也能花 $5 立即换，间隔满 24 小时即可。这个功能是后台自助的，不用开工单排队。
- **Pro 和 EB 有"首次连接全球可达"的保证，T1 没有。** 这条写在服务条款里，对做海外业务的人来说比线路参数更实用。
- **IP 不保证任何特定地区定位，也不保证某个网站或服务一定可用。** 这是官方条款的原话，别把"原生 IP"理解成"保证解锁 Netflix"。
- **支付方式**：支付宝、微信、PayPal、信用卡都能走。

T1 在换 IP 政策上是另一套规则，只能付费更换，间隔要求也更长。

## 香港和东京：结构一样，结论不一定一样

三个机房用的是同一套 Pro / EB / T1 分层，但落到具体价格和库存上，结论会反过来。

香港的情况是，Pro 的门槛相当高——HKG.Pro 的 TINY 档按 $39.90/月 的价格只给 500GB 流量。Eyeball 在香港曾经上线过（WEE 档一度做到 $24.90/月、TINY 档 $39.90 给 800GB），但这条产品线的供货状态反复变动，上线、下线、再补货都发生过。如果你冲着香港 EB 去，先确认它当天在不在售，别默认有货。

## 回到那个选择题：三步判断

**第一步，看你的宽带。**

电信用户选 Pro。CN2 GIA 是电信自家的精品网，回程优先级最高，晚高峰的差距在电信线路上体现得最明显。

联通和移动用户，洛杉矶的 EB 优先。EB 的回程分别走 AS9929（联通精品网）和 CMIN2（移动精品网），对这两家来说，体验和 Pro 的差距很小，而价格一样、流量翻倍，账很好算。

**第二步，算你的流量会不会在月内跑完。**

如果你只是搭博客、跑个小 API、做监控，1TB 到 1.5TB 大概率用不完，那 Pro 和 EB 对你来说差别就只有线路，选哪个取决于你更在意晚高峰的稳定还是端口带宽的余量。

如果你要跑中转、分发资源、多人共用，EB 多出来的那部分流量才是真金白银。

**第三步，看你有没有预算去追"最稳"。**

这里可以说得直白一点：如果你不是电信用户，也不是做对丢包极度敏感的业务，Pro 溢价买到的稳定性，你大概率感受不到。省下来的钱换成 EB 多出来的流量，更实在。

## 几个常见疑问

**Pro 和 EB 的硬件真的完全一样吗？**

分层是按网络配置切的，不是按硬件切的，两者用同一代 AMD EPYC 平台和 NVMe 存储。所以同一档位下，你拿到的算力没有区别。

**EB 的"尽力优化"和 Pro 的承诺差在哪？**

Pro 的回程是写明的固定 CN2 GIA 路径；EB 用的是 9929 / CMIN2 动态负载调度，路由会随网络状况调整。日常看不出来，拥堵时段才能分出高下。

**换 IP 会影响线路吗？**

不会，换的只是地址，网络配置不变。新 IP 由系统随机分配，不能指定段，换完要手动重启实例才生效。

**香港 EB 值得等吗？**

如果你需要香港节点的低延迟又嫌 Pro 贵，它确实是唯一的中间选项，但供货状态不稳定。别为了等它把项目拖住，洛杉矶的 EB 是随时能买到的替代方案。

最后一句实在话：这两个系列的差异，本质上是"用同样的钱，你是买回程优先级，还是买流量和端口带宽"。搞清自己的宽带是哪家、流量用多少，这个选择五秒钟就能做完。
